# Install Guide

Read the official docs for exact steps and current versions — do not rely on values from memory.

## Dependencies

Required components vary by deployment mode. Read before installing anything:

https://kserve.github.io/website/docs/install/dependencies

For pinned versions matching the current release, check `kserve-deps.env` in kserve/kserve.

## Install KServe

| Goal | Official guide |
|---|---|
| Predictive models (InferenceService) | https://kserve.github.io/website/docs/install/kserve-install |
| LLMs / generative AI (LLMInferenceService) | https://kserve.github.io/website/docs/install/llmisvc-install |
| Local model caching | https://kserve.github.io/website/docs/install/localmodel-install |
| Full overview | https://kserve.github.io/website/docs/install/overview |
| Upgrade | https://kserve.github.io/website/docs/install/upgrade-guide |
